## 二、最终选定的设计语言

**选定**：Apple 视觉规范的克制版——`#f5f5f7` 画布 + 白卡片 + 近黑文字 + 单一蓝色操作色，"video-first, distraction-free"（styles.css 2026-09-09 简化迭代注释原文）。

> **决策主体**：开发者拍板。在 Apple / Notion / Linear 三套设计规范中比较后选定 Apple（过程见 [会话总结.md](../会话总结.md) 决策表「UI 设计系统」行）；随后在 9/9 简化迭代中进一步去掉营销性元素，聚焦转换工作台本身。

**否决的方案**：

| 候选 | 否决理由 |
|---|---|
| Notion 风格 | 多色营销感与"安静可信的本地工具"定位冲突 |
| Linear 风格 | 深色开发工具感面向开发者，不匹配"普通用户"目标 |
| 保留旧版多彩主题 | 与"单一操作色 + 去视觉噪音"的简化方向冲突 |

**保留不动的部分**：

- 应用图标 favicon（`public/assets/app-icon.svg`）
- 保存位置记忆、按源格式记忆目标格式、中英双语（i18n）三项既有交互
- MIT 开源许可（LICENSE）

## 三、关键实装决策

> **决策主体标注**：`开发者拍板` = 开发者明确反馈后确定；`AI 提议 + 开发者确认` = AI 给方案、开发者验收通过；`实装中确定` = 开发过程中按约束落地。完整过程记录见 [会话总结.md](../会话总结.md)。

| 决策点 | 实装值（源码为准） | 选择依据 | 决策主体 |
|---|---|---|---|
| 设计体系 | Apple 克制版（见 §二） | 本地工具需要安静、可信、单一任务焦点 | **开发者拍板** |
| 画布 | `--bg: #f5f5f7` + 白卡片（非纯白画布） | 层次靠灰阶区分，不靠阴影和渐变 | AI 提议 + 开发者确认 |
| 主操作色 | `--accent: #0066cc` / `--accent-strong: #0071e3` | 唯一交互色，形成视觉锚点 | AI 提议 + 开发者确认 |
| 阴影 | `--shadow: none`，全局无阴影 | 层级用灰阶和留白表达，更"安静" | 实装中确定 |
| 圆角 | `--radius: 18px` | 大圆角亲和，匹配消费级工具气质 | 实装中确定 |
| 状态色去色彩化 | success=#0066cc、warning=#333333、error=#1d1d1f | **全 UI 无红无绿**，成功/警告/错误不靠颜色刺激，靠文案与图标 | 实装中确定（9/9 简化迭代） |
| 字体 | SF Pro Text（正文）/ SF Pro Display（标题） | Apple 系统字体栈，跨平台降级到 Segoe UI | AI 提议 + 开发者确认 |
| 流程组织 | 顶部三步流程条（选择文件→开始转换→保存结果）+ 保存位置栏 + 队列工作台 | 用户始终知道自己在哪一步 | **开发者拍板** |
| 队列卡片 | 缩略图 + 媒体信息行（体积/时长/分辨率/容器/编码）+ 状态签（"无需转码"/"无损快速转换"）+ 目标格式/编码下拉 | 面试题第 1 点（信息+缩略图）与第 3 点（智能直拷可视化）的直接落点 | **开发者拍板** |
| 响应式 | 1440（桌面）+ 390（窄屏）双断点实测 | 窄屏重排为单列而非缩放，避免横向溢出 | **开发者拍板** |
